# うごいた帳

運動して消費したカロリーと、運動の習慣を記録するウェブアプリです。

## できること
- 運動の種類を選んで、運動時間を入れると消費カロリーを自動で計算します
- 今日・今週の消費カロリー、連続して運動した日数、週の目標の達成度を表示します
- 直近14日のグラフ、今月の運動ごとの内訳、記録の一覧（削除もできます）を表示します

## 消費カロリーの計算方法
消費カロリー（kcal）＝ メッツ × 体重（kg）× 運動時間（時間）× 1.05

メッツは運動の強さを表す数字です。国立健康・栄養研究所「改訂版 身体活動のメッツ(METs)表」を参考にしています。

## 使い方
1. 右上に体重（kg）を入れる
2. 運動の種類を10種類から選ぶ
3. 運動時間を入れる（ボタンで5分〜90分も選べます）
4. 「記録する」を押すと、消費カロリーが記録されます
5. 今日・今週の合計、連続日数、グラフで運動習慣を確認できます

## ファイル構成
| ファイル | 内容 |
|---|---|
| index.html | 画面の骨組み |
| style.css | 見た目（色・大きさ） |
| data.js | 運動の種類のデータ |
| app.js | 計算・記録・グラフの処理 |

## 開き方
`index.html` をブラウザで開くだけで動きます。
